# Curso de Inteligencia Artificial

## Fundamentos y aplicaciones

**[Comenzar: Unidad 0 — Preparación del entorno](unidad00-entorno/README.md)**

Curso abierto en español para comprender la inteligencia artificial y construir soluciones aplicadas con Python. La ruta conecta los fundamentos, la IA simbólica, el aprendizaje automático, el aprendizaje profundo y los sistemas con modelos generativos.

El punto de partida de cada proyecto es una necesidad: qué problema queremos resolver, con qué datos, para quién y cómo comprobaremos el resultado. A lo largo del curso encontrarás aplicaciones en educación, energía, sensores, gestión ambiental y procesamiento de documentos.

## Objetivos

Al recorrer el curso podrás:

- Formular un problema y justificar una solución mediante reglas, modelos aprendidos o una combinación.
- Preparar datos y documentar su procedencia, calidad y limitaciones.
- Construir y comparar modelos con líneas base y métricas apropiadas.
- Identificar sobreajuste, filtración de información y evaluaciones engañosas.
- Interpretar errores, incertidumbre y efectos sobre distintos grupos.
- Desarrollar aplicaciones iniciales de visión, lenguaje y series temporales.
- Construir búsqueda semántica, RAG y agentes con herramientas acotadas.
- Integrar un modelo en una aplicación y documentar su operación y uso responsable.

## Antes de comenzar

Los conceptos iniciales se presentan desde cero. Para ejecutar y modificar las prácticas necesitas conocimientos de funciones, colecciones, archivos, excepciones y entornos virtuales de Python. Puedes estudiarlos en el [Curso de Python](https://github.com/lelyliliana/Curso-Python).

La matemática se explica cuando se necesita, con intuición, ejemplos pequeños y código. La ruta básica usa CPU. Las prácticas que requieren GPU, descarga de modelos o servicios externos se identificarán expresamente.

## Cómo estudiar

Sigue el orden de las unidades y trabaja un paso a la vez. En cada ejemplo:

1. Lee la pregunta y predice el resultado.
2. Ejecuta el programa con los datos incluidos.
3. Compara el resultado con la explicación.
4. Modifica una condición y explica qué cambia.
5. Resuelve los ejercicios antes de consultar las soluciones.

Las unidades combinan explicación, ejemplos desarrollados, instrucciones de ejecución, análisis del código, apartados **Experimenta**, errores frecuentes, ejercicios, reto aplicado y checklist.

Una respuesta de un modelo debe contrastarse con evidencia. Una métrica necesita contexto. Los proyectos incluyen una línea base y un análisis de sus limitaciones.

## Proyectos de aplicación

La ruta contempla tres talleres y un proyecto de elección:

- **Energía e IoT:** analizar lecturas de sensores, construir una línea base y evaluar predicciones o alertas.
- **Gestión ambiental:** organizar registros y apoyar una priorización mediante reglas o modelos, con explicación y revisión humana.
- **Educación y documentos:** recuperar información de un corpus y evaluar un asistente que cita sus fuentes.
- **Proyecto final:** delimitar un problema, desarrollar una solución y demostrar su funcionamiento y limitaciones.

Los datos de demostración se identificarán como públicos o sintéticos. Un resultado obtenido con datos sintéticos sirve para estudiar el procedimiento; no demuestra eficacia en una población real.

## Material disponible

Las **unidades 0 a 22 están desarrolladas**: 23 de las 36 unidades previstas. Incluyen explicaciones, ejemplos ejecutables, ejercicios, soluciones y retos. El material disponible cubre:

- **0–4:** entorno, formulación de proyectos, matemática aplicada y probabilidad.
- **5–9:** búsqueda, reglas, obtención y preparación de datos, exploración y visualización.
- **10–18:** líneas base, modelos supervisados y no supervisados, representaciones, validación, métricas e interpretabilidad.
- **19–22:** redes neuronales, PyTorch, visión por computador y procesamiento de lenguaje natural, con prácticas pequeñas en CPU y límites documentados.

La entrega más reciente enseña tokens, TF-IDF y clasificación de peticiones con separación por familias de textos, análisis de negación y ambigüedad, y recuperación verificable del modelo. Las **unidades 23 a 35 están pendientes de desarrollo**; la siguiente es Series temporales y sensores. Tener sus títulos definidos no equivale a haber terminado el curso.

El [seguimiento de continuidad y calidad](CONTINUIDAD.md) documenta el punto de partida, las entregas pendientes y los criterios de revisión. Para comprobar sintaxis, enlaces locales, ejemplos y pruebas de las unidades 0 a 22, ejecuta desde la raíz con el entorno virtual activo. La instalación inicial incorpora las dependencias numéricas y gráficas compartidas con la Unidad 9 y scikit-learn, introducido en la Unidad 13, y PyTorch para CPU, incorporado en la Unidad 20, y Pillow para leer imágenes en la Unidad 21. La Unidad 22 reutiliza estas dependencias numéricas y gráficas, sin añadir paquetes; las comprobaciones posteriores funcionan sin Internet:

```bash
python -m pip install -r unidad21-vision-computador/requirements.txt
python -m pip install -r unidad21-vision-computador/requirements-cpu.txt
python herramientas/verificar_curso.py
```

La instalación CPU indicada se comprobó en Linux x86_64 con Python 3.12. Para otras plataformas, consulta las [instrucciones y recursos de la Unidad 21](unidad21-vision-computador/README.md).
