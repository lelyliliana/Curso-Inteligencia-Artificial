# Protocolo u18-v1-modelos-fijos

[Unidad](../README.md) · [Datos](README.md)

Este protocolo define un experimento didáctico reproducible. No es un preregistro externo ni una evaluación secreta. Sus elecciones se codifican antes de leer validación o prueba; los resultados finales son públicos.

1. **Pregunta:** reconstruir modelos y sus límites con datos nuevos. No hay búsqueda de un ganador ni cambio automático de características según sus importancias.
2. **Consumo:** StandardScaler, medias y desviaciones poblacionales de entrenamiento, seguido de LinearRegression con intercepto. Se conserva la duplicación horas/minutos. Referencia: DummyRegressor con media de entrenamiento. Todos los parámetros se ajustan solo con entrenamiento; se conservan los valores predeterminados de la versión fijada salvo lo declarado.
3. **Alertas:** DecisionTreeClassifier con max_depth=2, min_samples_leaf=8 y random_state=18; demás parámetros predeterminados registrados en JSON. Referencia: DummyClassifier most_frequent. Única entrada: lectura. Ambas clases deben aparecer en entrenamiento. Grupo e ID sirven solo para auditoría y trazabilidad.
4. **Orden:** leer entrenamiento, ajustar una sola vez ambos predictores, leer validación y calcular diagnósticos. No hay reajuste con validación, ni siquiera al solicitar prueba.
5. **Caso local:** menor ID de validación en consumo. En alertas, menor ID de validación del grupo desplazado; si un conjunto alternativo no tiene ese grupo, menor ID de toda validación. No se elige por etiqueta, confianza ni tamaño del error. Esta elección no ofrece representatividad de todos los casos.
6. **Referencia lineal:** predicción en el vector de medias de entrenamiento. Reconstrucción exacta beta×z, no SHAP ni explicación aproximada. Se exporta también la ecuación en unidades originales. Dos coeficientes distintos pueden producir las mismas predicciones si las columnas son redundantes.
7. **Permutación:** solo consumo y solo validación. Bloques [horas], [minutos], [temperatura_c], [horas,minutos]. PCG64 con semilla 1818, 30 órdenes de filas compartidos entre bloques; se aplica cada orden al X original, no al resultado anterior. En el bloque de dos columnas se usa el mismo orden en ambas. Métrica: MAE permutado menos MAE original. Desviación poblacional, ddof=0. No se reajusta ni se permutan objetivos. No se presenta como intervalo inferencial ni efecto causal.
8. **Auditoría:** entrenamiento, validación y, si se solicita, cierre del árbol. Grupos estandar, desplazado, escaso y nuevo, incluyendo los vacíos. Se reportan n, positivos, negativos, VP/VN/FP/FN, precisión, recobrado, F1, tasas FP/FN/alerta y fracción de la muestra. División por cero produce null. Todas las filas válidas reciben predicción; no hay abstención. No se define un umbral automático de «equidad».
9. **Cierre:** abrir prueba solo después de concluir los diagnósticos, y únicamente con `--evaluar-prueba`. Evaluar el modelo fijo, sin repetir explicaciones o permutación sobre prueba. La línea base queda como referencia de desarrollo; no se compara para seleccionar otra versión en cierre. Validar separación de ID antes de evaluar. Documentar todos los errores, aunque contradigan una conclusión deseada.
10. **Cambios posteriores:** si coeficientes, entradas, grupos, umbrales o acciones cambian después de estudiar estas salidas, se debe identificar una nueva versión de desarrollo y una nueva evaluación independiente. Un nuevo informe sobre las mismas filas no ofrece evidencia independiente adicional.
11. **Artefactos:** JSON con versiones, fuentes, estado y resultados; CSV con predicciones; tres figuras de desarrollo. Los archivos publicados no contienen evaluación de prueba; los resultados de cierre se documentan en la unidad, las soluciones y la ficha. No se guarda un objeto pickle ni se carga código remoto.

La explicación se evalúa por fidelidad a la operación matemática y claridad de sus límites. La decisión de uso del ejemplo de alertas es **apto para docencia; no habilitado para operación real por esta evidencia**. Un menor error promedio no modifica esa decisión por sí solo.
